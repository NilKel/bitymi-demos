BITYMI demos

WebGPU 2D Gaussian splatting renders, baked from neural training to ride the mobile GPU.

All scenes use the same model: 3D_SH_res + --feature SV (Spherical Voronoi, K=7 sites/Gaussian, BC7 atlas). On Wi-Fi the indoor scenes load in a couple seconds; the outdoor ones are larger (50–800 MB) so save them for a fast connection.
