BITYMI demos

WebGPU Textured 2D surfel splatting with texture atlases baked from a neural representation.

All scenes use the same model: 3D_SH_res + --feature SV (per-surfel beta-scaled kernel, K=7 Spherical-Voronoi sites/surfel, BC7 residual atlas). On Wi-Fi the indoor scenes load in a couple seconds; the outdoor ones are larger so save them for a fast connection.

Both options use the new viewer built on top of WebSplatter with our 2DGS rasterizer ported on top — wait-free hierarchical Blelloch sort instead of the spin-wait Fuchsia radix that crashes on Snapdragon-class phones. Lite bakes the residual atlas at max_res 32 (¼ the bundle size, friendlier to phones with tight memory). HD uses the full max_res 64 atlas — sharper but ~4× larger.

Atlas format: BC7 ships everywhere desktop / iOS Safari / iPad Pro support texture-compression-bc. ASTC is the Adreno / Mali Android equivalent — pick this on a Snapdragon Android phone if BC7 falls back to color-only (no residual).

Color encoding: SV = Spherical-Voronoi softmax over K=7 sites per surfel. SB = SH-DC + K=2 spherical-beta directional lobes (sharper view-dependent specular). All 9 mip-360 scenes ship both SV and SB at HD in BC7 and ASTC; Lite is SV-only. SV/SB params are FP16-quantized in every HD bundle — empirically lossless (PSNR > 84 dB, SSIM ≈ 1.0 vs FP32 reference).
