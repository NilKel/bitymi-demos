BITYMI demos

WebGPU Textured 2D surfel splatting with texture atlases baked from a neural representation.

WebGPU 2D-surfel splatting with texture atlases baked from a neural representation. mip-360 ships in two flavours — Mixed (textured 2D surfels + untextured 3D EWA ellipsoids, the new default) and Original (textured 2D surfels only). Both use --feature SV (K=7 Spherical-Voronoi sites/surfel) and a paired-RVQ residual atlas. On Wi-Fi the indoor scenes load in a couple seconds; the outdoor ones are larger so save them for a fast connection.

Atlas

Viewer = our fork of WebSplatter with the 2DGS rasterizer ported on top: wait-free hierarchical Blelloch sort instead of the spin-wait Fuchsia radix that crashes on Snapdragon-class phones.

mip-360 scenes: paired-RVQ atlas (L=4 → L=2 collapsed K²=65536 codebooks, in-shader decode). Bit-equivalent quality to the BC7 baseline at ~3.5× less GPU memory; uses ~1.2× the fragment-shader cost.

Atlas format (medical / personal): BC7 ships everywhere desktop / iOS Safari / iPad Pro support texture-compression-bc. ASTC is the Adreno / Mali Android equivalent — pick this on a Snapdragon Android phone if BC7 falls back to color-only (no residual).
