Native Android APK for Meta Quest 2 that renders 2DGS + SV Gaussian scenes in immersive VR — same asset format as the flat viewer (.bitymi bundles), rendered directly against Vulkan + OpenXR without the browser.

Distributed sideloaded from this site. No Meta Store, no App Lab, no Meta review. Meta doesn't see the app, doesn't gate it, doesn't take a cut.

Why native (and not WebXR)?

WebXR + WebGPU was the first attempt: same code as the flat viewer, plus a stereo render loop. It compiled and submitted command buffers on Quest 2, but the Adreno 650 WebGPU driver crashes the GPU context during execution — for any combination of compute passes, and even for a minimal cleared-only render pass. A minimal WebGPU triangle works, but Halloumi's resource graph does not. That's the browser/driver floor as it stands in 2026 on Quest 2 hardware. See the WebXR fork (Halloumi-XR) for the diagnostic history.

Native Vulkan + OpenXR bypasses all of that: direct GPU access, mature drivers, and it opens the door to Quest-specific features (foveated rendering, controller tracking, spatial anchors).

How to install (one-time setup)

You only need to do this once per headset. After that, every future APK from this site installs with a single tap.

Step 1 · Enable Developer Mode on your Quest

  1. Create a free Meta developer organisation at developer.oculus.com — just pick any name, no company info or ID verification required.
  2. Open the Meta Quest phone app on your phone.
  3. Devices → [your Quest 2] → Developer Mode → toggle on.
  4. Reboot the headset once.

Step 2 · Allow installs from the Quest browser (recommended)

This makes future installs a single tap on this download link, right from the headset.

  1. On the headset, open Settings → Apps.
  2. Find Meta Quest Browser → toggle "install unknown apps" on.

Step 3 · Install

Option A · From the Quest browser (once above is done): open this page inside the headset, tap the download link, tap "install" when Android prompts. That's it.

Option B · From a PC via SideQuest: download SideQuest, plug your Quest in via USB-C, drag the APK onto the headset icon.

Option C · From a PC via ADB (advanced): adb install halloumi-quest.apk.

What's under the hood

Full pipeline reworked to Vulkan compute shaders + OpenXR. Same conceptual passes as Halloumi-WS (cull → preprocess → radix sort → tile raster) but as GLSL/SPIR-V compute shaders on Vulkan, with stereo rendering via OpenXR's projection layer + view matrices. Asset format unchanged — the same .bitymi bundles served to the flat viewer load directly. BC7 / ASTC atlas support handled by native texture compression paths that Vulkan supports directly.

Reference implementation lives at /home/nilkel/Projects/Halloumi-Quest — see docs/PLAN.md for the full port plan and phase breakdown.
